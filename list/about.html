О проекте

📊 Генератор регулярных сеток

Инструмент для создания сеток на основе географических данных с открытыми исходниками.

Возможности:

  • ✅ Выбор области на карте OSM
  • ✅ Рисование произвольной области
  • ✅ Поиск по названию региона
  • ✅ Выбор проекции (Меркатор, UTM, Альберс, Ламберта)
  • ✅ Настройка размера ячейки
  • ✅ Экспорт в SVG, PNG, PDF, SHP

Используемые технологии:

  • 🗺️ Leaflet + OpenStreetMap
  • 📐 Turf.js для геообработки
  • 📤 shp-write для SHP
  • 🖼️ html2canvas для PNG
  • 📄 jsPDF для PDF
